# Architecte Sonore

Skill Cursor / Grok Bot — directeur artistique hip-hop & R&B francophone.

Transforme un brief en pack **Suno v6 Prestige** (HookGenius 5 parties, Exclude, Lyrics, Arc L'onde, Edits V6, script `.txt`).

## Fichier

- [`SKILL.md`](./SKILL.md) — skill prêt à coller / importer

## Usage

1. Ouvre `SKILL.md`
2. Briefe mood, thème, genre/BPM, punchy ou soft
3. Colle le pack généré dans Suno Create Custom (v6)
